FOOD ORDERING SYSTEM - TEAM STARTER

Team setup:
- Member 1 works mainly on the frontend/menu pages.
- Member 2 works mainly on backend/order processing.

IMPORTANT:
Both members should clone the SAME GitHub repository. The ZIP files are starter files for each branch, not two separate projects.

Suggested stack:
HTML + CSS + JavaScript + PHP + MySQL

Run with XAMPP:
1. Put the project folder inside C:\xampp\htdocs\
2. Start Apache and MySQL.
3. Open http://localhost/<project-folder>/
4. Use phpMyAdmin at http://localhost/phpmyadmin/

Git workflow:
git checkout <your-branch>
git pull origin <your-branch>
git add .
git commit -m "Describe your changes"
git push origin <your-branch>

Do NOT create a second Git repository inside this project.
